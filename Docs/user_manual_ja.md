# FolderTreeExporter ユーザーマニュアル (日本語)

`FolderTreeExporter` は、Unity プロジェクト内のフォルダ構造をプレーンテキストのツリー形式として生成・プレビュー・エクスポートできる Unity エディタ拡張機能です。  
BOOTH や GitHub の README、配布用パッケージの仕様書、納品構成図などの作成に最適です。

## 1. 動作環境
- **対応 Unity バージョン**: Unity 2022.3.22f1 以降、および Unity 6 (6000.x)
- **対応 OS**: Windows / macOS
- **依存関係**: 特になし（標準の UnityEditor API のみで動作）

---

## 2. 起動方法
以下のいずれかの方法でツールウィンドウを開くことができます。

### 方法 A: メニューバーから起動
Unity の上部メニューバーから **`dennokoworks` > `FolderTreeExporter`** を選択します。

### 方法 B: Project ウィンドウの右クリックから起動（おすすめ）
Project ウィンドウ内の任意のフォルダを右クリックし、**`dennokoworks` > `Export Folder Tree`** を選択します。  
選択したフォルダが自動的に対象としてセットされた状態でウィンドウが開きます。

## 3. 画面構成と基本操作

ツールウィンドウは dennokoworks デザインシステム（フローティングデザイン）に準拠した、以下の構成になっています。

### ① トップバー（ヘッダー）
- **ウィンドウタイトル**: `FolderTreeExporter`
- **バージョン表示**: 現在のバージョン（例: `v1.0.0`）を表示します。GitHub リモートリポジトリ（`master` ブランチ）を定期的に自動チェックし、更新がある場合は緑色で強調表示されます。
- **再確認ボタン (`↻`)**: アップデートの有無を手動で即座に再取得します。
- **言語切替ボタン (`EN` / `JA`)**: クリックで表示言語を日本語と英語で切り替えます（デフォルト: 日本語）。選択した言語はエディタ再起動後も保持されます。

### ② メイン領域（スクロールカード）
- **「対象フォルダ」カード**:
  - **フォルダ フィールド**: 対象のフォルダアセットが表示されます。Project ウィンドウからフォルダを直接ピッカー選択することも可能です。
  - **「参照」ボタン**: エクスプローラー／Finder 風のフォルダ選択ダイアログから `Assets` 配下のフォルダを指定できます。
  - **ドラッグ＆ドロップ エリア**: Project ウィンドウからフォルダを枠内にドラッグ＆ドロップするだけで、素早く対象を切り替えられます。
- **「設定」カード**:
  - **出力モード**: ツリーに何を含めるかを選択します（フォルダ+アセットタイプ / フォルダのみ / ファイル込み）。
  - **ツリータイプ**: 階層の表現スタイルを選択します（標準ツリー / ASCIIツリー / Markdownリスト）。
  - **アセット件数を表示**: 種別ごとのファイル件数（例: `[Texture: 5, Material: 2]`）を表示するかどうかのトグルです。
  - **Markdownコードブロックで囲む (```)**: 出力全体を ```` ``` ```` で囲むトグルです。
- **「プレビュー」カード**:
  - 生成されたツリー構造を等幅フォントでリアルタイムにプレビュー表示します（手動の全選択やコピーも可能）。
  - 右上の「更新」ボタンから手動再生成も可能です。プロジェクト内のファイル変更時にも自動追従します。

### ③ フッター（アクション部）
- **「クリップボードにコピー」ボタン**: 生成されたツリーテキスト全体をワンクリックで OS のクリップボードにコピーします。
- **「ファイルに保存」ボタン**: クリックするとメニューが表示され、テキストファイル（`.txt`）または Markdownファイル（`.md`）として任意の場所に保存できます。

### ④ ステータスバー
- コピー完了やファイル保存結果などの状態メッセージを表示します。

> [!NOTE]
> 巨大なフォルダ階層を指定した場合、Unity の描画負荷を避けるためプレビュー画面上は先頭部分のみ切り詰めて表示されますが、「クリップボードにコピー」や「ファイルに保存」では常に**全文**が出力されます。

## 4. 機能詳細と出力例

### 出力モード（3種類）

#### 1. フォルダ + アセットタイプ (デフォルト)
フォルダ構造とともに、そのフォルダ直下に含まれているアセットの種別（Model, Texture, Material 等）をタグ形式で表示します。配布パッケージの全体像を把握しやすく、最も推奨されるモードです。

```
MyAvatar
├── Animations [Animation]
├── Materials [Material]
├── Models [Model, Texture]
└── Prefabs [Prefab]
```

#### 2. フォルダのみ
サブディレクトリの構造のみを出力します。大まかなディレクトリ設計をドキュメント化したい場合に便利です。

```
MyAvatar
├── Animations
├── Materials
├── Models
└── Prefabs
```

#### 3. ファイル込み
個別ファイル名も含めた完全なツリーを出力します。詳細なファイル一覧を提示したい場合に最適です。

```
MyAvatar
├── Animations
│   └── Idle.anim
├── Materials
│   └── Body_Mat.mat
├── Models
│   ├── Body.fbx
│   └── Texture.png
└── Prefabs
    └── MyAvatar.prefab
```

---

### ツリータイプ（3種類）

貼り付け先の環境やフォントに合わせて、3つの記号スタイルから選択できます。

| スタイル名 | 使用記号・書式 | 推奨される貼り付け先 |
| :--- | :--- | :--- |
| **標準ツリー（Unicode罫線）**<br>*(デフォルト)* | `├── `, `└── `, `│   ` | GitHub、Discord、Notion、各種コードブロック |
| **ASCIIツリー** | `+-- `, `\-- `, `\|   ` | 等幅フォントのメモ帳、古いテキストエディタ、レガシー環境 |
| **Markdownリスト** | `- ` (スペース2文字インデント) | プロポーショナル（可変幅）フォント環境、Webフォーム、Notion等 |

#### 出力スタイルの比較例

- **標準ツリー（Unicode罫線）**:
  ```
  Folder
  ├── SubFolderA
  │   └── AssetA
  └── SubFolderB
  ```
- **ASCIIツリー**:
  ```
  Folder
  +-- SubFolderA
  |   \-- AssetA
  \-- SubFolderB
  ```
- **Markdownリスト**:
  ```markdown
  - Folder
    - SubFolderA
      - AssetA
    - SubFolderB
  ```

---

### 表示オプション

#### アセット件数を表示
「フォルダ + アセットタイプ」モード時にチェックを入れると、各種別のファイル件数を併記します。

- **OFF**: `Models [Model, Texture]`
- **ON**: `Models [Model: 1, Texture: 4]`

#### Markdownコードブロックで囲む (```)
チェックを入れると、テキスト全体の先頭と末尾に ```` ``` ```` を付与します。

```markdown
```
MyAvatar
├── Materials [Material: 3]
└── Models [Model: 1, Texture: 4]
```
```

## 5. アセット種別の自動判定について

拡張子（.png や .fbx 等）による単純判定ではなく、Unity の `AssetDatabase` を用いてアセットの実際の型に基づいて自動分類します。

- **判定例**:
  - `Model`: FBX、OBJ、および VRM / glTF などのインポートモデル
  - `Prefab`: プレハブアセット
  - `Texture`: テクスチャ画像（PNG, TGA, PSD 等）
  - `Material`: マテリアル
  - `Shader`: シェーダー、ComputeShader、ShaderInclude 等
  - `Animation` / `Animator`: アニメーションクリップ、アニメーターコントローラー
  - `Script` / `AssemblyDefinition`: C# スクリプト、asmdef
  - `Scene`, `Audio`, `Video`, `Font`, `ScriptableObject`, `Text` など
- **除外ルール**:
  - `.meta` ファイルは常時自動的に除外されます。
  - `.` から始まる隠しファイル・隠しフォルダ（`.git` 等）も自動的に除外されます。

## 6. おすすめの活用シーンと設定の使い分け

| 利用用途 | おすすめの設定組み合わせ |
| :--- | :--- |
| **Discord や GitHub の Issue / PR** | **標準ツリー** ＋ **Markdownコードブロック: ON**<br>→ 等幅フォントで崩れず、きれいに表示されます。 |
| **BOOTH 商品説明・Webページ** | **Markdownリスト** または **標準ツリー ＋ コードブロック**<br>→ プロポーショナルフォントでも箇条書きとして読みやすくなります。 |
| **配布物の README.md** | **フォルダ + アセットタイプ** ＋ **標準ツリー** ＋ **コードブロック: ON**<br>→ パッケージ全体の構成とアセット種別が一目で分かります。 |
| **ファイル納品書・構成一覧** | **ファイル込み** ＋ **ASCIIツリー** または **標準ツリー** |
