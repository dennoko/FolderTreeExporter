# FolderTreeExporter 要件定義・機能仕様書

## 1. 概要
`FolderTreeExporter` は、Unity プロジェクト内の指定したフォルダの階層構造をプレーンテキストのツリー形式として生成・表示・エクスポートする Unity エディタ拡張機能です。  
ドキュメント作成（README、仕様書、納品フォルダ構成図など）や共有をスムーズに行うことを目的としています。

## 2. 対応環境
- **Unity 2022.3.22f1** (LTS)
- **Unity 6** (6000.x)
- OS: Windows / macOS 両対応

## 3. 起動・アクセス方法
1. **メニューバー**
   - `dennokoworks` > `FolderTreeExporter` をクリックして専用エディタウィンドウ（タブ）を開く。
2. **Project ウィンドウのコンテキストメニュー**
   - 任意のフォルダを右クリック > `dennokoworks` > `Export Folder Tree` を選択すると、そのフォルダが指定された状態でツールウィンドウが直接開く。

## 4. 機能要件

### 4.1 フォルダ指定機能
- **ドラッグ＆ドロップ (D&D)**: Project ウィンドウから対象フォルダをウィンドウ内のドロップエリアまたはオブジェクトフィールドにD&Dして指定可能。
- **オブジェクトフィールド**: 直接フォルダアセットを選択・変更可能。
- フォルダ指定（または変更）された時点で、自動的にツリー構造テキストを生成・プレビュー表示する。

### 4.2 出力モード（ツリー生成形式）
ラジオボタンまたはドロップダウンにより、以下の出力モードを切り替え可能：

| モード | 説明 | 備考 |
| :--- | :--- | :--- |
| **フォルダ + アセットタイプ** | フォルダ構造に加え、各フォルダ内に含まれるアセットの種別をタグ形式で表示 | **デフォルト** |
| **フォルダのみ** | ディレクトリ構造のみを出力 | 概要把握向け |
| **ファイル込み** | フォルダ直下の個別ファイル名も含めた完全なツリーを出力 | 詳細構成向け |

### 4.3 表示オプション
- **アセット件数の表示トグル**（「フォルダ + アセットタイプ」モード時）:
  - **OFF (デフォルト)**: アセット種別名のみを表示  
    例: `Models [Model, Texture, Material]`
  - **ON**: アセット種別ごとのファイル件数も併記  
    例: `Models [Model: 2, Texture: 5, Material: 1]`
- **Markdownコードブロック化トグル**:
  - **OFF (デフォルト)**: プレーンテキストとして出力
  - **ON**: 出力テキスト全体を Markdown コードブロック（```` ``` ````）で囲んで出力  
    （Discord や GitHub 等へ貼り付ける際の等幅フォント崩れ防止用）

### 4.4 アセット判定および除外ルール
- **Unity アセット種別による分類**:
  - ファイル拡張子に依存せず、Unity のアセット種別（Prefab, Texture, Model, Material, Audio, Shader, Script 等）に基づいて分類・表記。
- **除外ファイル**:
  - `.meta` ファイルは常時自動的に除外。
  - 隠しファイル／フォルダ（`.` から始まるもの）もデフォルトで除外。

### 4.5 ツリー表現フォーマット（ツリータイプ切り替え）
ドロップダウンまたはツールバーより、以下の3種類のツリースタイルを切り替え可能：

| スタイル名 | 使用記号 / 形式 | 特徴・推奨ペースト先 |
| :--- | :--- | :--- |
| **標準ツリー（Unicode罫線）**<br>*(デフォルト)* | 枝: `├── `<br>末尾: `└── `<br>縦線: `│   ` | 見た目が美しく標準的な形式。等幅フォント環境やコードブロック併用に最適。 |
| **ASCIIツリー** | 枝: `+-- `<br>末尾: `\-- `<br>縦線: `\|   ` | 全角半角の文字幅差によるズレが起きにくい、半角英数記号のみの形式。 |
| **Markdownリスト** | 箇条書き: `- `<br>インデント: 半角スペース2文字 | 箇条書きリストとして解釈されるため、プロポーショナル（可変幅）フォント環境でも階層が崩れない。 |

### 4.6 コピー＆エクスポート機能
- **テキストプレビューエリア**:
  - 生成されたテキストを表示するスクロール可能なテキストエリア。手動での全選択・コピーも可能。
- **手動編集モード（v1.1追加）**:
  - プレビューカード右上の「手動編集」トグルをONにすることで、プレビュー内のツリーテキストを直接キーボード編集可能。
  - 各行の横に注釈・補足コメントを追記するなどの用途に対応。
  - 手動編集ON時は、外部変更による自動上書きをロックして編集内容を保護。
  - 手動編集ON時は、「クリップボードにコピー」および「ファイルに保存」も編集後の最新テキストを出力。
  - トグルOFF時、変更が破棄される前に確認ダイアログを表示して誤操作を防止。
- **クリップボードへコピー ボタン**:
  - ワンクリックで生成されたツリーテキスト（または手動編集後のテキスト）全体をOSのクリップボードへコピー。
  - コピー成功時にはステータスバーに通知を表示。
- **ファイル保存（エクスポート）ボタン**:
  - ファイル保存ダイアログを表示し、テキストファイル（`.txt` または `.md`）としてローカルに保存可能。

## 5. UI / UX 仕様
- **レイアウト構成**:
  1. **ヘッダー部**: タイトル、バージョン表示（リモート自動確認）、再確認ボタン（↻）、言語切替ボタン（`EN` / `JA`）
  2. **対象フォルダ カード**: フォルダ選択フィールド（D&D対応）、参照ボタン、ドロップエリア
  3. **設定・オプション カード**:
     - 出力モード選択（フォルダ+アセットタイプ / フォルダのみ / ファイル込み）
     - ツリータイプ選択（標準ツリー / ASCIIツリー / Markdownリスト）
     - オプションチェックボックス:
       - [ ] アセット件数を表示
       - [ ] Markdownコードブロックで囲む (```` ``` ````)
  4. **プレビュー カード**:
     - 見出し、[ ] 手動編集トグル、更新ボタン
     - スクロールビュー付きテキストエリア（手動編集対応）
  5. **アクション部（フッター）**:
     - 「クリップボードにコピー」ボタン
     - 「ファイルに保存」ボタン
  6. **ステータスバー**: 状態通知（成功／エラー）
